# Astro Website - Landing Page de Ventas 🌐

Este directorio contiene el sitio web público de marketing y ventas de la startup, desarrollado en Astro para máxima velocidad, rendimiento y SEO.

## 🚀 Comandos
- `npm run dev`: Inicia el servidor local de desarrollo.
- `npm run build`: Genera el build optimizado para producción en `dist/`.
