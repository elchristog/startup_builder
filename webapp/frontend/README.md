# Web App Frontend (React) ⚛️

Aplicación Web principal construida en React con soporte para:
- `/src/login`: Pantalla de autenticación y selección de tipo de acceso.
- `/src/customers`: Dashboard interactivo y herramientas para clientes post-compra.
- `/src/team`: Workspace de operaciones y administración para el equipo interno.

## 🚀 Ejecución Local
```bash
npm install
npm run dev
```
